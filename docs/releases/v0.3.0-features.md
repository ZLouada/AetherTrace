## ⚡ Executive Summary

**AetherTrace v0.3.0** is a major UI/UX modernization and architectural hardening release. Building upon the robust distributed tracing, proxy interception, time-travel replay, and evaluation engines of v0.2.0, this release transforms AetherTrace into a **cohesive, high-density, keyboard-first developer workstation** inspired by the precision and craftsmanship of tools like Linear, Raycast, and the VS Code debugger.

Every surface—from the core execution Directed Acyclic Graph (DAG) and real-time breakpoint interceptor to the multi-agent experiment and evaluation studios—has been elevated with a unified design system, accessible dark typography, decoupled zero-latency layouts, and fluid interaction ergonomics.

## 🚀 What's New in v0.3.0

### 1. Design System 2.0 & Visual Identity
- **AetherTrace Orange (`#ea580c`) Primary Accent:** Introduced formal brand accent tokens used exclusively for active focus states, live execution pulses, and primary actions.
- **Pure Dark Foundation:** Standardized neutral dark hierarchy:
  - Surface 0 (Canvas): `#09090b` (pure dark)
  - Surface 1 (Sidebars/Drawers): `#111114` (dense background)
  - Surface 2 (Elevated Cards & Nodes): `#18181b` (card background)
  - Surface 3 (Hover & Active Highlights): `#27272a`
  - Border Subtlety: 1px `#27272a` borders throughout, replacing heavy dividers.
- **Zero Glassmorphism:** Stripped out all decorative `backdrop-blur` and transparency hacks in favor of solid, opaque, performant dark surfaces.
- **Semantic State Mapping:** Unified execution status colors:
  - **Success:** Emerald (`#22c55e`)
  - **Running / Active:** AetherTrace Orange (`#ea580c`)
  - **Error / Failure:** Crimson (`#ef4444`)
  - **Paused / Intercepted:** Amber (`#f59e0b`)
  - **Mocked / Cached ($0.00):** Cyan (`#06b6d4`)
  - **Stalled / Warning:** Purple (`#8b5cf6`)
- **Tailwind Utility Clean-up:** Purged invalid classes (`py-0.2`) and negative margin workarounds across all components.

---

### 2. Workspace Shell & Window Geometry 2.0
- **Application Rail (48px):** Leftmost vertical navigation strip providing single-click routing between primary workspaces:
  - `D` — Debugger (Flight Deck)
  - `F` — Diff Arena (Run Comparison)
  - `E` — Experiment Studio (Prompt & Model Matrix)
  - `V` — Evaluation Studio (Deterministic Assertions)
- **Persistent Draggable Splitters:** Draggable vertical dividers for the Run Sidebar and Inspector Drawer with persistent `localStorage` memory (`aethertrace:sidebar-width`, `aethertrace:inspector-width`) and double-click-to-reset.
- **Keyboard Collapsible Sidebar:** Press `⌘B` or `Ctrl+B` to collapse or expand the Run Sidebar, granting the execution graph maximum canvas area.
- **Consolidated TopBar:** Streamlined header displaying the active run badge, quick run picker dropdown, live execution duration/cost metrics, view toggles, and global action buttons (Chaos, Breakpoints, Clear).

---

### 3. Execution DAG & Dual-Density Span Nodes
- **Decoupled 0ms Layout Engine:** Complete decoupling of Dagre layout computations from interactive selection, hover highlights, and pin states. Clicking, hovering, or pinning nodes updates React Flow node references in-place with **0ms visual latency**, eliminating graph re-renders and coordinate jumps.
- **Dual-Density Node Modes:**
  - **Compact Mode (220×48px):** Minimalist horizontal pills displaying icon, model/tool label, latency badge, and cost tag. Engineered for massive multi-agent traces (1,000+ spans).
  - **Detailed Mode (320px cards):** Full telemetry cards with model parameters, token breakdown (input vs completion), error previews, and execution badges.
  - **Adaptive Density Toggle:** Auto-switches based on graph node count or user preference via the density control.
- **Span Pinning (`P`):** Pin key reference spans with `P` to maintain glowing borders and keep them pinned in view while navigating complex subgraphs.
- **Single-Key Graph Navigation:** Step forwards and backwards through the execution DAG in topological order using `J` / `K` or `[` / `]`.
- **Agent Group Nodes:** Visual bounding boxes grouping concurrent tool calls and sub-agent executions under their parent agent container.
- **Critical Path Highlighting:** Automated $O(V+E)$ bottleneck analysis illuminating the exact causal dependency chain dictating end-to-end execution latency.

---

### 4. Interactive Waterfall Timeline 2.0 (`T`)
- **Calibrated Time Axis Ruler:** Horizontal zoom controls (25% to 400%) with calibrated microsecond gridlines and relative offset timestamps.
- **Sticky Event Columns:** Left-hand metadata column remains docked in view while horizontally panning across long-duration traces.
- **Paused Playhead Guideline:** Distinct amber playhead marker and guideline indicating the precise millisecond where an execution is currently held at a breakpoint.
- **Bidirectional Sync:** Hovering or selecting any span in either the DAG or Timeline instantly highlights and scrolls to the corresponding element in the other view.

---

### 5. Event & Node Inspector Drawer 2.0
- **Searchable Inspector Tabs:**
  - **Overview:** Latency breakdown, token accounting, cache origin, and execution status.
  - **Prompts & Messages:** Formatted chat message history with role badges (`system`, `user`, `assistant`, `tool`).
  - **Response Payload:** Model outputs, function arguments, and tool results with one-click JSON copy.
  - **Lineage & Provenance:** Upstream parent span, child spans, causal dependencies, Git commit SHA, and branch metadata.
  - **Time-Travel Fork IDE:** Inline parameter mutation editor for zero-cost replay and iterative prompting.
- **Exact Resource Accounting:** Monospace display of prompt tokens, completion tokens, duration in milliseconds, and calculated API costs with distinction between estimated and reported pricing.

---

### 6. Real-Time Breakpoint Interceptor HUD
- **Zero-Code-Change Breakpoint Hold:** Suspend live agent requests mid-flight at the local proxy layer without modifying application code.
- **Persistent Breakpoint HUD:** Top-of-screen floating control center showing the held span, model, agent name, and live hold timer.
- **Single-Key Resolution Actions:**
  - `Space` — **Continue / Forward:** Release the request unmodified to the upstream provider.
  - `M` — **Mock ($0.00):** Return an immediate synthetic response directly from the proxy, avoiding LLM billing.
  - `E` — **Edit / Mutate:** Alter the prompt payload, inject system directions, or switch model targets before forwarding.
  - `Esc` — **Abort:** Terminate the request with an immediate HTTP 403.
- **Conditional Breakpoint Triggers (`⌘⇧B`):** Configure automated breakpoints triggered on error status, token thresholds, specific agent roles, or regex patterns.

---

### 7. Side-by-Side Diff Arena 2.0
- **Execution Graph Regression Testing:** Select any two runs (e.g., baseline vs forked replay) to inspect topological deltas.
- **Provenance Scorecard:** Instant delta calculation comparing latency savings, token reduction, and financial cost variance.
- **Visual Delta Indicators:** Added, removed, mutated, and identical spans highlighted with clear semantic diff colors.
- **Side-by-Side Payload Inspector:** Unified diff view for prompt alterations and response variances.

---

### 8. Experiment & Evaluation Studios 2.0
- **Experiment Studio (`E`):**
  - Run multi-variant test suites across different model targets (e.g., GPT-4o vs Claude 3.5 Sonnet vs Llama 3) and prompt versions.
  - Compute aggregate pass rates, cost per run, and median latency across variant matrices.
- **Evaluation Studio (`V`):**
  - Deterministic assertion DSL evaluating JSON schema compliance, latency budgets, cost limits, and keyword constraints.
  - **Zero-Cost Local Evals:** 100% deterministic local evaluations without expensive, flaky LLM-as-a-judge roundtrips.
  - **Culprit Span Routing:** One-click jump from a failing assertion directly to the faulty span in the DAG canvas.

---

### 9. Raycast-Style Command Palette 2.0 (`⌘K`)
- **Local SQLite FTS5 Full-Text Search:** Sub-millisecond BM25-ranked search indexing every run, span, prompt message, and tool output.
- **Semantic Filter Chips:** Instantly filter search results by `All`, `Runs`, `Spans`, `Commands`, and `Workspaces`.
- **Keyboard-First Ergonomics:** Full arrow key navigation, `Enter` to execute, and instant dismissal via `Esc`.

---

### 10. Accessibility & Quality Hardening (WCAG 2.1 AA)
- **Contrast Elevation:** Elevated all secondary and tertiary metadata text from low-contrast `text-zinc-500` to high-contrast `text-zinc-400` (5.8:1) and `text-zinc-300` (8.9:1), exceeding WCAG 2.1 AA standards on pure dark backgrounds.
- **Modal Focus Trapping:** Active keyboard focus trapping and automatic `previousActiveElement` restoration across all dialogs, drawers, and the Command Palette.
- **ARIA Landmark & Tree Semantics:** Full semantic tagging including `role="dialog"`, `role="region"`, `role="treeitem"`, `role="listbox"`, and `role="option"`.
- **Stress-Tested Performance:**
  - 0ms visual selection and hover latency.
  - 157ms layout calculation for 100 spans; 825ms for 1,000 spans.
  - Zero memory leaks across extended debugging sessions.

## 📦 Getting Started with v0.3.0

### Run Locally via CLI
```bash
# Start AetherTrace Proxy (:4000) and Flight Deck (:3000)
npx aethertrace start

# In another terminal, run an autonomous multi-agent simulation
npx aethertrace sim
```

### Point Your Agents to AetherTrace
Change your agent framework's OpenAI or Anthropic `baseURL` to `http://localhost:4000/v1`:

```python
import openai

client = openai.OpenAI(
    base_url="http://localhost:4000/v1",
    api_key="your-api-key",
    default_headers={"X-Agent-Name": "ResearchAgent"}
)
```

No code changes. Instant visual debugging, cost tracking, and time-travel replay.
